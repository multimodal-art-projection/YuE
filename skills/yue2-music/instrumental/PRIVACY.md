# 分发内容与隐私

这个发布包只包含 skill 说明、辅助源码、专门编写的测试短谱、公开依赖的固定版本与校验哈希。示例不是用户会话中的作品；包内不含原用户谱、原会话、音频、训练数据、模型权重、凭据、内部实验代号、集群账号、内网地址或开发机绝对路径。

模型 repo ID、commit revision 和 SHA-256 是公开下载与完整性校验信息，不是访问凭据。合法版权署名保留。CPU 修谱工具只在本机读写；安装和模型获取调用 pip/Hugging Face，生成调用本地 YuE2 推理。辅助脚本没有把乐谱、prompt 或音频上传到远端的功能。这项说明不替代对所用 agent 平台和第三方依赖的隐私审查。

发布 ZIP 与运行后的工作目录不同。准备和生成目录按用户请求保留原谱、prompt、配置、音频及调试记录，可能含用户作品、本机路径、GPU 信息或报错上下文。不要把整个工作目录、虚拟环境、缓存、凭据文件或日志夹入 skill 分享包。用户作品交回本人；未经授权不用于其他人的公共示例。分享音频时只选需要的音频和经复核的说明。

迁移时在接收方机器配置下载所需身份；不要复制或打印 token。`--offline` 可以让已有模型的生成阶段不再从 Hub 取文件，但不代表整个 agent 平台离线。

发布包使用专门编写的示例、公开模型名称和固定 ZIP 时间戳，注释及扩展字段为空。版本和哈希保留用于复现；检查范围是所发 ZIP 的全部条目、文本内容与元数据，不包含对所有第三方依赖的安全审计。

`run` 和 `cover` 自动导出 `listen/`，也可单独运行 `share`：只复制音频、实际 prompt、标准谱和少量公开生成参数，不带原谱、修谱记录、GPU 型号、本机路径、native 配置或错误日志。模型写谱与参考音频转谱的完整记录保留在本机工作目录，不自动放入分享目录。导出只在本机创建文件，不上传。音频、prompt 和标准谱本身仍是用户内容，公开分享前需要用户授权。

维护者打包时应使用显式文件清单，并在干净解压目录运行 `python3 -B scripts/verify_bundle.py --strict`，排除多余文件和符号链接。不要递归压缩已经运行过的 skill 目录。
