# 修谱规则

## 目标格式

```abc
X:1
T:
M:4/4
L:1/32
Q:1/4=81
V: Vocal clef=treble name="Vocal Melody" snm="Vocal"
V: Ins clef=treble name="Ins Melody" snm="Inst."
K:Bm
% intro
V: Vocal
"Bm"z32|"G"z32|
V: Ins
B8d8f8d8|g16f8e8|
```

固定头部顺序、空 T 和声部名称。每组 1–4 小节，先 Vocal 后 Ins，逐小节时长相同。Vocal 的休止前写和弦，Ins 只能是一条单旋律。正文与结尾使用普通 `|`，不留反复号或 `|]`。

结构改变时写一次 `% intro` / `% verse` / `% pre-chorus` / `% chorus` / `% bridge` / `% interlude` / `% outro` / `% instrumental`。重复副歌仍要写全，不能删除音乐。拍号/调号改变要另起一组，两轨同时写同样的 M/K。保留 5/8、7/8 等拍号，不为省事改成 4/4。速度只有头部一个整数四分音符 BPM。

## 音高和时值

`C`=MIDI 60，`c`=72，`C,`=48，`c'`=84。K:Bm 中 F/C 是 F♯/C♯。`^`升、`_`降、`=`还原。训练风格按**同字母跨八度**传播临时变音，直到小节线/调号变化；原输入可能采用不同约定。转换混合八度变音时用明确 MIDI 事件或显式还原号，不沿用另一个解析器的隐含假设。

L:1/32 下四分音符=8、4/4 小节=32、5/8=20、6/8=24。改 L 要同步缩放所有时值。L 分母为 2 的幂，并至少为每种拍号分母×4的整数倍。常用 L:1/32。

时值整数只用 1,2,3,4,6,8,12,16,24,32,48；省略数字1。E10→E8-E2，z10→z8z2。持续长音拆分用连音，不能变成重复起音。连音连接同一实际音高，不可连休止、空起连音或结尾悬空。

无标记整小节休止写 Z；同组连续休止压成 Z2–Z4。带和弦/调号的休止保留事件位置，例如 `"Bm"z24"F#"z8`，不能压成 Z 后丢和声。

## 常见修复

| 输入 | 处理 |
|---|---|
| Markdown/YAML 围栏、BOM、弯引号、头部乱序 | 去外层包装，规范字段、引号与空白。保留原件。 |
| M:C、Q:81、K:B minor | 规范成 M:4/4、Q:1/4=81、K:Bm。非四分音符速度先换算。 |
| 任意轨名、数字轨、内联 V 字段 | 先建逐轨时间线，选主旋律再映射 Ins；不能全局替换后串接同时声部。 |
| 多轨、叠音 `[Bdf]`、叠音内空格 | 选主旋律轨，轨内叠音默认取最高音；和声保留为标签，配器写 style。不要在所有伴奏声部机械取最高音。 |
| 主旋律跨轨交接 | 按段落拼接有意义的主题，保留原空隙；重叠按主题选择，记录依据。 |
| MIDI program、动态、渐强、奏法 | 移出 ABC；重要乐器、力度走向和奏法写 style，不能写到歌词中。 |
| w:/W:/原歌词 | 只保留原件；请求歌词为空或只有结构标签。 |
| 反复、1/2房子、D.C./D.S./Coda | 按实际演奏顺序展开，核对次数和落点；不能直接删符号造成缺段。 |
| 三连音、破节奏 A>B、分数时值 | 先算真实时长。附点通常可精确保留；非2的幂时值要显式量化到足够细的网格，记录偏差，保持小节总长。 |
| 倚音、装饰音、连奏线 | 主旋律关键装饰音分配真实时值；表现性指令写 style。不能吞掉难解析的乐句。 |
| 弱起、尾小节 | 识别后补明确休止对齐，或写明确的短拍号；记录增加的静默，不偷偷拉长音符。 |
| 欠拍/超拍 | 先查 L、连音、字段作用域、缺休止和反复。明显漏休止可最小补齐并记录；超拍不可截音，必要时重新分小节或问关键澄清。 |
| 缺拍号/速度/调号 | 从其他声部及上下文恢复；仍未知则记录最少假设。可按明确音高输出 K:C 加变音，但不能声称识别了原调。 |
| 变速 | 训练格式只用一个速度；可按总时长选代表速度并记录，rubato 写 style。要求精确保留多速度时要说明冲突并确认折中。 |
| 不常见调式 | 先还原实际音高，再用支持的大小调号和显式变音表达，不能只换 K 导致移调。 |
| 多首 X: | 分别处理，不擅自拼成一首。 |

和弦后缀支持：无后缀、m、dim、aug、7、maj7、m7、dim7、m7b5、sus4、sus2、6、m6、7sus4、m(maj7)，支持根音升降与斜杠低音。C:maj→C。Cmaj9、A7alt 等需有意识地缩为合适核心和弦，把延伸色彩写 style，记录简化，不能盲删后缀。冲突和弦要查旋律、低音与前后文。无和弦且未要求新配和声时用 melody 模式。

## 复核

依次对照原谱与缩编的曲式、小节数、主旋律音高/起音/时长、连音、和声切换时刻、拍号/调号变化，再运行 prepare。事件编译器只证明你给的事件与输出一致，不能证明事件读对了。保留原谱及缩编说明。

本包的校验独立实现训练风格约束，不冒充原训练源数组重建。若所在环境已有原训练序列化器，可额外核验，但它不是依赖。

修谱记录示例：

